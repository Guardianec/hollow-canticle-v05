## Using the references

Read the images together with the archived brief when working on animation,
combat presentation, Shinobi, world geometry, item clarity, tutorial or rendering
quality. Image labels and example numbers are reference material; resolve any
conflicts with the user's active request and agreed gameplay requirements.

Keep these files as documentation. They are not runtime textures, sprites or
screenshots of the implemented game. Preserve the originals when adding later
references. Earlier visual references remain in [v05](../v05/).
