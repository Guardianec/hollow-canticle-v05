You are continuing development of **Hollow Canticle**.

This release is:

# Hollow Canticle v0.5.0 — Blender-Only Visual Rebuild

This is NOT primarily a gameplay release.

The current v0.4.0 gameplay foundation is strong enough that the largest remaining weakness is now unmistakably **visual fidelity**.

The game currently has a recognizable style, but it still looks too much like a procedurally assembled low-poly/block game.

The target is significantly closer to the supplied reference art:

- seamless architecture;
- sculpted environment silhouettes;
- believable materials;
- detailed but stylized characters;
- strong fog;
- deep voids;
- monumental spaces;
- sophisticated lighting;
- far less obvious cube construction;
- far greater texture variety;
- visual cohesion across procedural rooms.

The goal is NOT photorealism.

The goal is:

> **high-quality stylized dark-fantasy indie visuals**

while retaining:

- browser deployment;
- Three.js;
- procedural generation;
- deterministic gameplay;
- good performance.

# 5. CURRENT SYSTEM LIMITATION

The current game builds most environment geometry from primitives such as:

- boxes;
- rounded boxes;
- cylinders;
- cones;
- low-poly spheres.

This was a successful prototype strategy.

But v0.5 must deliberately move beyond it.

Do NOT attempt to achieve the reference by writing another 2,000 lines of:

```ts
box(...)
cylinder(...)
sphere(...)
```

That is specifically what this release is replacing.
